## Вопросы для самопроверки

### 1. Почему папку `venv` не нужно коммитить в Git?
Папка `venv` содержит тысячи служебных файлов библиотек, бинарников и внутренних путей, привязанных к конкретной операционной системе и локальной машине. Коммитить её в Git не нужно, потому что она сильно раздувает объём репозитория, засоряет историю коммитов и создаёт конфликты при работе других разработчиков на других компьютерах.

### 2. Что произойдёт, если другой разработчик склонирует репозиторий без папки `venv`? Как ему восстановить окружение?
После клонирования репозитория без `venv` у разработчика не будет установленных сторонних библиотек (например, `requests` или `numpy`), поэтому при запуске кода возникнет ошибка импорта (`ModuleNotFoundError`)[cite: 1, 9].
